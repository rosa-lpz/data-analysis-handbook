# Key elements



here are 10 key elements that should be in your documentation:

1. Summary Details – Contains high level information such as Business Owner, Technology Owner, Refresh Frequency, Summary Statistics, etc.
2. Access – Information on the security setup of the dashboard
3. Purpose of Dashboard – Business description of the dashboard
4. Data Sources – Information on the data sources used in the dashboard
5. Available Filters – Filters available for use in the dashboard. These filters can be global or page specific.
6. Predefined Filters – Filters not available for use in the dashboard. These filters can be global or page specific.
7. Dashboard Illustrations – Screen shots of the dashboard
8. Parameters – Parameters used in the dashboard
9. Calculated Fields – Calculated fields that have been created in the data source(s). These can be based on other calculated fields or fields contained in the physical data source.
10. Tables and Fields – Tables and fields that are being directly pulled from a database or file
