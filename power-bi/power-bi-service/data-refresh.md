# Configure scheduled refresh of data

To schedule the data refresh for an specific Power BI dashboard that is already uploaded to Power BI service (Cloud) we should follow these steps:

* Go to the semantic model
* Click on the "Refresh" dropdown and then select the "Schedule refresh" button.
* The we should see the following sections:
  * Credentials in the semantic model
  * Schedule refresh and performance optimization
